# Changelog

## 1.0.0 - Draft community release

- Added independently selectable CPU, memory, storage, uptime, network speed, OS, IP and Tailscale IP telemetry.
- Added optional local status page using the same design system as the dashboard.
- Added muted off-white light theme and dark theme.
- Reworked dashboard to server panels only; removed sidebar.
- Added refresh selector, theme control and settings cog.
- Added Local IP/hostname, Tailscale and Direct IP server connection modes with configurable port/protocol.
- Added community-site source with `/builder/`, `/demo/status/`, `/demo/dashboard/`, `/docs/` and `/download/`.
- Added live demo-agent configuration with IP telemetry disabled.
- Added Apache-2.0 licence.
